# Prova Paulista — Correção | Jogo estilo plataforma

Jogo web estático pronto para Vercel. Não usa backend nem banco de dados.

## Como publicar na Vercel
1. Crie um repositório no GitHub e envie todos os arquivos desta pasta.
2. Em https://vercel.com/ clique em **Add New → Project**.
3. Importe o repositório.
4. Não informe framework/build command. O projeto é HTML/CSS/JS puro.
5. Clique em **Deploy**.

## Conteúdo
O jogo usa somente a seção **“Introdução à Administração, Legislação e Pessoas - 51061”** da Prova Paulista enviada.
Foram transformadas em desafios:
- Questão 1 — recrutamento;
- Questão 2 — competências técnicas e socioemocionais;
- Questão 3 — modalidades de treinamento;
- Questão 4 — cinco afirmações de Certo/Errado sobre avaliação de treinamento.

Total: 8 respostas pontuáveis.

## Áudio
- `assets/acerto.mp3`: som enviado para resposta correta/moedas.
- `assets/erro.mp3`: som enviado para resposta incorreta.

## Observação
Os arquivos de imagem enviados foram mantidos como base visual. A moeda foi recortada da imagem enviada para permitir a animação de moedas caindo sem o fundo quadriculado.
